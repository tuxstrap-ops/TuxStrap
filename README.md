# 🐧 TuxStrap

<p align="center">
  <img src="gui/assets/logo.svg" width="128" height="128" alt="TuxStrap Logo" />

<p align="center">
  <strong>Fast, modern, zero-lag and unblocked Roblox client bootstrapper for Linux.</strong><br>
  Türkiye'deki Roblox erişim engelini harici VPN olmadan, 0 gecikmeyle (wire ping) aşan ve Sober istemcisini optimize eden Linux başlatıcısı.
</p>

---

## ⚡ Hızlı Kurulum (Tek Komut)

Terminalinizi açın ve tek satır komutu yapıştırın:

```bash
curl -sSL https://raw.githubusercontent.com/tuxstrap-ops/TuxStrap/main/install.sh | bash
```

> **Not:** Projeyi klonlayarak kurmak isterseniz:
> ```bash
> git clone https://github.com/tuxstrap-ops/TuxStrap.git
> cd TuxStrap
> ./install.sh
> ```

---

## 🚀 Özellikler

- 🛡️ **Zero-Ping DPI & DoH Bypass:** Harici VPN'lere gerek kalmadan yerel tel gecikmesiyle (50-65 ms) doğrudan bağlantı.
- 🎮 **In-Game X11 HUD:** Oyun oynarken `F4` ile ekranda açılan donanım, gecikme ve profil monitörü.
- ⚡ **FPS & Performans Optimizasyonu:** Mesa GLThread, 360 FPS kilidi, CPU Performance Governor sabitleme.
- 🎨 **Minimalist & Modern Arayüz:** Sade, göz yormayan Steam/Prism Launcher tarzı temiz arayüz.
- 🌍 **Çoklu Dil Desteği:** Canlı Türkçe & İngilizce arayüz geçişi.

---

## 🗑️ Kaldırma (Uninstall)

```bash
tuxstrap --uninstall
```
